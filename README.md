# Heptabase-style AI Tutor Skill

Codex / Claude Codeで、目標に合わせた学習コースを作り、少しずつ学び、理解を確かめ、次回に続きを再開するためのスキルです。日本語を既定とし、他の言語でも使えます。

Heptabaseの公式スキルではありません。[AI Tutor](https://heptabase.com/ai-tutor)の学習フローに着想を得た独立実装です。Heptabaseアカウントや専用APIキーは不要です。利用するAIツール自体の契約・使用量は別途適用されます。

## このフォルダで使う

スキル本体は [skills/heptabase-ai-tutor/SKILL.md](skills/heptabase-ai-tutor/SKILL.md) です。`.agents/skills/` と `.claude/skills/` から同じ本体へ相対シンボリックリンクを設定しています。

このフォルダで新しいCodex / Claude Codeのセッションを開いて使います。検出されなければ再起動するか、下記の個人用インストールを利用してください。

Codex:

```text
$heptabase-ai-tutor Pythonの辞書を学びたい。C#経験あり、1回15分。例から教えて。
```

Claude Code:

```text
/heptabase-ai-tutor Pythonの辞書を学びたい。C#経験あり、1回15分。例から教えて。
```

自然文で「Heptabase AI Tutor風に、この資料を使って体系的に教えて」でも利用を依頼できます。

## 他のフォルダでも使う

まずリポジトリを取得します。

```sh
git clone https://github.com/togo13duke/heptabase-ai-tutor-skill.git
cd heptabase-ai-tutor-skill
```

このディレクトリから以下を実行すると、個人用のスキルフォルダにコピーできます。既に同名のファイルやリンクがあれば上書きせず停止します。使用するツールのブロックだけ実行してください。

Codex:

```sh
mkdir -p "$HOME/.agents/skills"
if [ ! -e "$HOME/.agents/skills/heptabase-ai-tutor" ] && [ ! -L "$HOME/.agents/skills/heptabase-ai-tutor" ]; then
  cp -R skills/heptabase-ai-tutor "$HOME/.agents/skills/heptabase-ai-tutor"
else
  echo '同名スキルがあるためコピーしませんでした。'
fi
```

Claude Code:

```sh
mkdir -p "$HOME/.claude/skills"
if [ ! -e "$HOME/.claude/skills/heptabase-ai-tutor" ] && [ ! -L "$HOME/.claude/skills/heptabase-ai-tutor" ]; then
  cp -R skills/heptabase-ai-tutor "$HOME/.claude/skills/heptabase-ai-tutor"
else
  echo '同名スキルがあるためコピーしませんでした。'
fi
```

コピー版は元ファイルの変更に自動追従しません。プロジェクト用と個人用の両方に同名を置くと重複・優先順位の影響があるため、通常はどちらか一方を使ってください。導入先は [Codex公式資料](https://learn.chatgpt.com/docs/build-skills) と [Claude Code公式資料](https://code.claude.com/docs/en/skills) を参照しています。

## できること

| やりたいこと | 進め方 |
| --- | --- |
| 全体像から学ぶ | 目標・経験・時間に合わせたシラバスを作成 |
| 自分に合う開始位置を探す | 必要に応じて短い現在地チェックを行い、実回答から開始位置や補う前提を調整。希望すれば詳しく診断でき、途中で説明にも切り替えられる |
| 寓話で全体像をつかむ | 概念名を伏せた物語で関係の形を見せ、何の話か推測してから、対応表と物語が通用しない点を解説 |
| 用語の怖さを外す | つまずきそうな用語を推定し、あだ名→一言→最小の例→正式名称の順で説明 |
| 資料から学ぶ | Web・PDF・Markdown・YouTube字幕・Heptabase MCP・NotebookLM MCPから教材化 |
| 無理なく進める | 一つのPartを説明し、小さな確認問題で区切る |
| 理解を確かめる | 一問ずつ、実践場面への適用と理由を確認。誤答にはヒントを一つ出して再挑戦、2回目の誤答で正解を説明 |
| 理解度テスト | 解説せずに、易しい問題から段階的に5問を一問ずつ出題 |
| 説明して確かめる | 自分の言葉で説明し、誤りや曖昧な箇所があればその場で止めて指摘 |
| フラッシュカード | 自分のノートから二択でない復習カードを15枚、定義・手順・よくある間違いの分類つきで作成 |
| 定着させる | 再開時に前回の要点を一問想起してから進む |
| 難易度を調整 | 前提を補い、未着手のシラバスと時間配分を更新 |
| 中断・再開 | 回答待ちの問題も含め、Markdownから続きを復元 |
| 簡略化を後で回収する | 省いた条件や定義を「近道の帳簿」に記録し、回収時期が来たら前の説明とつなげて補う |
| 総まとめを作る | 修了時に、確かめた理解・一枚の早見表・用語の対応表・残った近道をまとめたパスポートを作成 |
| 知識を残す | 資料・教材・洞察ノートを相対リンクで関連づける |
| 記録を点検する | 標準ライブラリだけのスクリプトで、状態の食い違い・リンク切れ・存在しない出典IDを検出 |

例:

```text
このPDFを使って、仕事で設計判断ができるところまで教えて。週3回、各20分。
Pythonを独学しました。まず短い質問で理解を確かめて、必要なところから学習計画を作って。
このYouTubeを字幕から読み、初心者向けの学習コースにして。
難しすぎる。具体例を増やして、今日は5分だけ。
σとかp値とか、記号を見るだけで嫌になる。やさしく教えて。
今学んでいるTCPの再送・輻輳制御・フロー制御を、寓話で全体像が分かるように説明して。
理解度チェックはスキップして、次回用の質問を残して。
さっき学んだ第3章の理解度を確認したい。まだ解説せず、問題を出して。
このノートからフラッシュカードを作って。
欠席した友人に教えるつもりで説明するので、間違っていたら止めて。
今日の気づきを概念ノートに保存して。
learning/python-dicts/ の続きから再開して。
統計のコースを終えたので、学んだことの総まとめを作って。
```

## 教え方

学習を止めるのは、内容の難しさより用語や記号への怖さであることが多い、という考え方を取り入れています。Silvanus P. Thompson『Calculus Made Easy』（1910）と、その教え方をスキルにした [x-made-easy-skill](https://github.com/baibanbao/x-made-easy-skill)（MIT License）を参考にしました。本の執筆用だった手法を、対話で進む継続学習に合わせて作り直しています。

- **つまずきリスト**：怖そうな用語を質問攻めにせず推定し、使う直前に一つずつ外す。
- **今は気にしなくてよいこと**：後回しにしてよいことと、いつ気にすればよいかを各Partで示す。
- **近道の帳簿**：簡略化はしてよく、誤りは教えない。本では付録でまとめて精算するしかないが、継続学習では回収の時期を予約し、その時期が来たら補える。
- **ことばの規律**：「明らかに」「自明」を使わず、その一歩を書く。例は出典か自作かを区別し、数値は検算する。
- **練習ルート**：運動・実験・機器操作などは、出発点・操作・確かめ方・直し方・終わり方を書いて段階的に進める。
- **寓話**：概念名を伏せた物語で関係の形を先に見せ、推測してもらってから対応表で答え合わせをする。物語が通用しない点も必ず書く。
- **パスポート**：Thompsonが巻末に渡した公式一覧にならい、修了時に一枚で見直せるまとめを作る。

詳しくは [teaching-style.md](skills/heptabase-ai-tutor/references/teaching-style.md) を参照してください。

## MCPを資料の入力に使う

Heptabase MCP / NotebookLM MCPが接続されていれば、指定したカード・ホワイトボード・ノートブック・ソースを読み取って授業を作れます。MCPなしでも同じスキルを使えます。入力元を変えても、教材と進捗はローカルMarkdownに保存します。

```text
Heptabase MCPの「分散システム」ボードにある資料から、学習コースを作って。
NotebookLM MCPの「統計入門」ノートブックを使って、1回15分で教えて。
今回はMCPを使わず、docs/tutorial.pdfだけで教えて。
```

実際のツール機能を確認して読み取り方を選びます。NotebookLMの照会結果しか取得できない環境では、その旨を明記して扱います。未接続ならエクスポート、元URL、貼り付けでも利用できます。MCPの入力指定だけで外部サービスにノートや資料を追加することはありません。詳しくは [MCP入力の手順](skills/heptabase-ai-tutor/references/mcp-inputs.md) を参照してください。

## 学習記録

作業フォルダの `learning/<course-slug>/` に保存します。

- `GOAL.md`：目標、経験、学び方
- `SYLLABUS.md`：学習順序、進行、理解の根拠
- `SOURCES.md`：資料と実際に読んだ範囲
- `PROGRESS.md`：現在位置、回答待ちの問題、問題番号・回答回数・ヒントの状況、次の一手
- `SHORTCUTS.md`：簡略化した説明と回収する時期
- `PASSPORT.md`：修了時の総まとめ
- `sessions/`：教材、理解度チェック、まとめ
- `notes/`：必要なときに保存する概念ノート

現在地チェック・理解度テストだけなら `REVIEW.md` と `PROGRESS.md`、カード作成だけなら `FLASHCARDS.md` と `PROGRESS.md` で始められます。シラバスなしでも再開できます。回答を添えて再開すると、前回のヒントや回答回数を引き継いで評価します。

保存後、Pythonが使える環境ではスキルが記録を自己点検します。手動でも実行できます（Python 3.8以上、標準ライブラリのみ）。

```sh
python3 skills/heptabase-ai-tutor/scripts/check_course.py learning
```

「エラー」は再開を妨げる食い違い（`awaiting_answer` なのに質問がない、SOURCESにない資料ID、リンク切れなど）、「注意」は確認すべき点（回収時期を過ぎた近道、根拠のない `demonstrated` など）です。文の分かりにくさや事実の誤りは検出しません。

状態値をバッククォートで囲んだ記録や、複数行のコード・選択肢を含む回答待ちも点検できます。存在しないフォルダや未知のオプションは終了コード2、記録のエラーは1、正常時は0を返します。`--strict` を付けると注意も終了コード1になります。

CodexとClaude Codeで同じ作業フォルダを開けば同じ記録を参照できます。同じコースへの同時書き込みは避けてください。`learning/`には個人の回答や資料が入るため、この配布フォルダではGit管理対象外にしています。

## 再現の範囲

授業の進め方をスキルで定義します。HeptabaseのホワイトボードUI、クリック操作、専用のPDFビューア、動画再生、アカウント同期は再現していません。図はMarkdown表やMermaid、資料閲覧は各AI環境の機能を利用します。

Web・PDF・字幕の取得はホスト環境のツール次第です。取得できない資料を読んだことにせず、代わりの資料や提供された字幕で進めます。Heptabaseへの直接保存は、ユーザーから依頼があり、対応する接続がある場合だけ行います。
