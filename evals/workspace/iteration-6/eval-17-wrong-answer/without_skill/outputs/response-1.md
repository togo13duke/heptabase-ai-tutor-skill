## 小さな例で確かめる

顧客テーブル
| id | 名前 |
|----|------|
| 1 | 佐藤 |
| 2 | 鈴木 |
| 3 | 田中 |

注文テーブル(customer_id)は、佐藤が2件、鈴木が1件、田中が0件です。

- **INNER JOIN**: 両方のテーブルに対応する行がある組み合わせだけ残します。注文が0件の田中は結果に出てきません。
- **LEFT JOIN(顧客が左)**: 左の顧客は全員残します。注文がない田中は、注文側の列がNULLになって残ります。

```sql
SELECT c.id, c.名前, COUNT(o.id) AS 注文件数
FROM 顧客 c
LEFT JOIN 注文 o ON o.customer_id = c.id
GROUP BY c.id, c.名前;
```

結果は 佐藤=2、鈴木=1、田中=0 になります。
