今回の位置：**T1.P1／キーと値（約5分）**。到達点は「商品名から在庫数を取り出す書き方が分かること」です。

```python
stock = {"apple": 3}
print(stock["apple"])  # 3
```

`"apple"`が**キー**、`3`が**値**です。`{キー: 値}`で対応を作り、`stock["apple"]`で対応する値を取り出します。C#の`Dictionary<string, int>`でもキーから値を取るのと同じ考え方です。

ここで`["apple"]`は「先頭を取る」ではなく「appleというキーを探す」という意味です。また、Pythonのこの例では型を宣言していないので、C#と同じ型制約が働くとは考えないでください。
