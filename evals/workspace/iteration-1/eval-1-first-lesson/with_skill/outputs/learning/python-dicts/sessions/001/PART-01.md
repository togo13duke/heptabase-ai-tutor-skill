# T1.P1：キーで値を取り出す
在庫数を商品名から探す例です。
```python
stock = {"apple": 3}
print(stock["apple"])  # 3
```
`"apple"`がキー、`3`が値です。`{キー: 値}`で対応を作り、`辞書[キー]`で値を取り出します。
C#の`Dictionary<string, int>`と同様に、キーを使って値を探します。ただしPythonではこの例に型の宣言を書いていません。C#の型制約がそのまま働くわけではありません。
`["apple"]`は「先頭を取る」という意味ではなく、指定したキーを探します。存在しないキーの扱いは後のTopicで扱います。
