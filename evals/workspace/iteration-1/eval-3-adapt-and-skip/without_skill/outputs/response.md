辞書を「名前を書いた箱」と考えてみてください。

```python
stock = {"apple": 3}
```

これは **「appleという名前の箱に、3が入っている」** というイメージです。

そして、

```python
stock["apple"]
```

は **「appleの箱の中身を見る」** という意味です。取り出される値は `3` です。C#で `Dictionary` のキーを指定して値を読む操作と同じです。
