まず、プログラムの「値」は、`2`のような数や`"pen"`のような文字のことです。辞書は、それに探すための名前を付けておけます。

```python
stock = {"pen": 2}
```

これは「penという名前に、2という数を結び付けた」と読んでください。

```python
stock["pen"]  # 2を取り出す
```

角括弧の中に**探す名前**を書きます。C#のDictionaryでキーを指定するのと同じ役割です。ここでは「名前 → それに対応する数」の一組だけで十分です。`["pen"]`は順番や位置の指定ではありません。
