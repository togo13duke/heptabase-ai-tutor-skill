# T1.P1 母集団と標本
全員を調べるのが難しい場面で、対象の全体と調べる一部を区別します。

説明用の例（チューターによる補足）：学校の生徒全員の通学時間を知るために、30人に聞く。
- 母集団：知りたい対象の全体。この例では生徒全員。
- 標本：実際に調べる一部。この例では30人。

[S1のNotebookLM照会回答](../../sources/S1-query.md)は、母集団の一部である標本から推定すると説明しています。引用ソースIDはs1。位置・ページ・URLは未提供、原文照合未検証です。

チューターの補足：標本の結果が全体と必ず一致するわけではありません。標本は全体そのものではなく、全体を考えるための一部です。
