第2問 / 全3問の続きです。今日はこの問題の「返る値」と「辞書の中身」の違いを確かめるところまで、約2分で進めましょう。

1行目の `0` は合っています。2行目は `False` になります。

```text
0
False
```

`get("book", 0)` は、`book` が見つからないときに `0` を返します。この操作で辞書の中身は変わらず、`stock` は `{"pen": 2}` のままです。そのため、`"book" in stock` は `False` になります。「0が返る」ことを「bookに0が入る」ことと結びつけたところを修正しましょう。

同じ点を、値を変えて一度だけ確かめます（自作問題）。

```python
stock = {"apple": 3}
print(stock.get("pear", 7))
print("pear" in stock)
```

**2行の出力はそれぞれどうなりますか。理由も一言お願いします。**
