# 壺運びのヨウと、山の老僧

むかし、谷の村にヨウという壺運びがいた。

山の上の寺に、老僧がひとりで住んでいた。老僧は村の長老から「千の壺に分けて納めた一冊の経」を受け取り、その中身を一字も違えず、順番どおりに書き写す役目を負っていた。壺を運ぶのがヨウの仕事だった。

## 一 番号と木札

ヨウは壺の肩に、一から千まで番号を刻んだ。道中で順番が入れ替わっても、老僧が並べ直せるようにするためだった。

老僧は壺を受け取ると、小さな木札に一行だけ書いてヨウに返した。

「次は四十二番を待つ」

「四十一番を受け取った」とは書かない。「ここまでは全部そろった、次はこれが欲しい」と書く。だから、ある札が途中でなくなっても、その次の札が届けばヨウには全部わかった。

## 二 砂時計

山道は険しかった。壺はときどき割れ、ときどき崖から落ちて、そのまま消えた。

ヨウは壺を出すたびに砂時計をひっくり返した。砂が落ちきる前に「その壺を受け取った」とわかる札が戻らなければ、同じ番号の壺をもう一度作って送った。

砂時計の長さは決めていなかった。札が戻ってくるまでの時間を毎回測って、ふだんより少しだけ長めになるように削り直していた。短すぎると、まだ道の途中にある壺まで作り直してしまう。長すぎると、消えた壺を延々と待つことになる。
作り直した壺までまた戻らなかったときは、砂時計を倍の長さに替えた。山で何か大きなことが起きているのかもしれないから、焦って何度も送るのはやめたのだ。

## 三 同じ札が三枚

ある日、三十七番が崖から落ちた。三十八番、三十九番、四十番は無事に着いた。

老僧は三十八番から四十番を捨てずに脇へ置き、壺が届くたびに同じ札を返した。

「次は三十七番を待つ」
「次は三十七番を待つ」
「次は三十七番を待つ」

同じ札が続けて三枚届いたとき、ヨウは砂時計を待たずに三十七番を作り直した。後ろの壺は届いているのに三十七番だけを待っている。それなら三十七番が消えたのだと、砂が落ちる前にわかったからだ。

## 四 老僧の棚

老僧の写経は丁寧で、そのぶん遅かった。届いた壺は小さな棚に置き、一つ書き写すごとに一つ片づけた。

あるとき、ヨウが張り切って一度に壺を運びすぎた。棚に入りきらなかった壺は軒先に置かれ、夜露で中身がだめになった。壺は割れずに着いたのに、無駄になってしまった。

それからというもの、老僧は木札の端にもう一言書き添えるようになった。

「次は四十二番を待つ。棚の空きは、あと五つ」

ヨウは、老僧が受け取ったと書いてきた番号から先は、その空きの数を超えて壺を道に出さないことにした。
「空きは、あと零」と書かれた札が来ると、ヨウは運ぶのをやめた。ただ、それきり黙って待ち続けることはしなかった。老僧が棚を空けて「空いたよ」と書いた札が途中で落ちていたら、二人とも待ちぼうけになってしまう。だからヨウはときどき、ほんの小さな空の壺だけを送って「棚はどうですか」と尋ねた。

## 五 吊り橋

山道の途中に一本の吊り橋があった。

その橋は、ヨウのものではなかった。東の村も西の村も、それぞれの寺へ壺を運ぶのに同じ橋を渡っていた。橋のたもとには渡し守がいて、渡りきれない壺をしばらく並べて待たせた。並べる場所がいっぱいになると、渡し守は後から来た壺を黙って谷へ落とした。

ヨウの村には古い言い伝えがあった。
昔、どの村の壺運びも、老僧の棚の空きだけを見て壺を送っていた。橋が混んで壺が谷に落ちる。落ちた壺を作り直して、また送る。その壺がさらに橋を混ませる。やがて橋の上は作り直しの壺ばかりになり、どの寺にもほとんど何も届かなくなった。棚はどこもがら空きだったのに。

だからヨウは、老僧の棚とは別に、自分の胸の中にもう一つの数を持っていた。村の人はそれを**慎み**と呼んだ。

- 旅の初めは、慎みは「一つ」。橋の様子がわからないから、壺を一つだけ出す。
- 札が一枚戻るごとに、慎みを一つ増やす。すると往復するたびに、一つ、二つ、四つ、八つと倍になっていく。
- 胸には**かつて痛い目を見た印**も刻んであった。慎みがその印まで育ったら、それからは一往復ごとに一つずつしか増やさない。
- 砂時計が落ちきるまで札が戻らなかったら、橋で何か大きなことが起きている。そういうときは印を今の慎みの半分に刻み直し、慎みは「一つ」からやり直す。
- 同じ札が三枚届いたときは、後ろの壺はまだ橋を渡れている。だから「一つ」までは戻らず、慎みを半分にして、そこから少しずつ増やしていく。

一度に道へ出す壺の数は、**老僧の棚の空き**と**胸の慎み**の小さいほうに決めていた。

ヨウには橋が見えなかった。渡し守は何も教えてくれない。わかるのは、札が遅れたり、来なかったり、同じ札が続いたりすることだけだった。ヨウはそれを橋の声として聞いた。

東の村の壺運びも、西の村の壺運びも、同じ作法を守っていた。だから橋は落ちなかった。混めば誰もが少し退き、空けば誰もが少しずつ進んだ。誰もが、一人で使うときより少しだけ少なく、けれど確かに届けていた。

## 六 弟子の問い

ある年、老僧のもとに若い弟子が来た。弟子はヨウに尋ねた。

「どうしてそんなに面倒なことをするのですか。壺をありったけ送れば早いでしょうに」

ヨウは指を三本立てた。

「一つ目。道は壺を落とす。だから番号を刻んで、札を待ち、来なければ作り直す。
二つ目。お師匠さまの棚は小さい。だから棚の空きを聞いて、それより多くは送らない。
三つ目。橋はみんなのものだ。橋は何も言わないから、札の遅れと欠けから様子を察して、自分で退く」

「一つ目は失くしたものを取り戻すため。二つ目は受け取る人のため。三つ目は、同じ道を使う見知らぬ誰かのためだよ」

## 答え合わせ：これはTCPの話でした

ヨウは**送信側のTCP**、老僧は**受信側のTCP**、吊り橋は**ネットワークの途中にあるルーター**です。

| 寓話 | TCP |
|---|---|
| 壺 | セグメント（データの小分け） |
| 壺の肩の番号 | シーケンス番号 |
| 「次は四十二番を待つ」という木札 | 累積ACK（確認応答番号＝次に欲しい番号） |
| 届かなかった壺を作り直して送る | **再送** |
| 札が戻るまでの時間を測って削り直す砂時計 | RTTの計測と、それをもとにしたRTO（再送タイムアウト） |
| 作り直しても戻らなければ砂時計を倍に | RTOの指数バックオフ |
| 後の壺を脇に置いて三十七番を待つ | 順序の入れ替わったセグメントを受信バッファで保持し、順番どおりに並べる |
| 同じ札が三枚 → 砂を待たずに作り直す | 重複ACK3つによる**高速再送**（Fast Retransmit） |
| 老僧の棚 | 受信バッファ |
| 「棚の空きは、あと五つ」 | 受信ウィンドウ（rwnd）の通知 → **フロー制御** |
| 「空きは零」でも小さな壺で尋ねる | ゼロウィンドウプローブ |
| 吊り橋と渡し守、谷に落とされる壺 | ルーターのキューがあふれてパケットが捨てられる |
| 昔、橋の上が作り直しの壺ばかりになった | 輻輳崩壊（1986年ごろに実際に起きて、輻輳制御が入るきっかけになった） |
| 胸の「慎み」 | 輻輳ウィンドウ（cwnd） → **輻輳制御** |
| 一つ、二つ、四つ、八つ | スロースタート |
| かつて痛い目を見た印 | スロースタート閾値（ssthresh） |
| 印を越えたら一往復に一つずつ | 輻輳回避（加算的増加） |
| 砂時計切れ → 印を半分にして「一つ」から | タイムアウト時：ssthreshを半分にし、cwndを最小からやり直す |
| 札三枚 → 慎みを半分にして続ける | 高速リカバリ（乗算的減少）。「足すのはゆっくり、引くのは半分に」をまとめてAIMDと呼ぶ |
| 棚の空きと慎みの小さいほう | 実際に送れる量 ＝ min(rwnd, cwnd) |
| 皆が同じ作法なので橋が落ちない | 公平性。輻輳制御は一人ひとりが自主的に守る約束事 |

### 全体像を一言ずつで

- **再送**：消えたものを取り戻す。番号とACKとタイマー、それに重複ACKで気づく。
- **フロー制御**：**受け取る相手**をあふれさせない。相手が「空きはいくつ」と**はっきり教えてくれる**。
- **輻輳制御**：**途中の道（ネットワーク）**をあふれさせない。誰も教えてくれないので、ロスや遅れから**推測する**。

フロー制御と輻輳制御はよく混同されます。見分けるときは「誰を守るのか」「その情報を誰が教えてくれるのか」を考えてみてください。ここが違います。

補足：寓話の慎みの増やし方・減らし方は、教科書でよく使われる古典的な方式（TCP Reno）に合わせています。いまのLinuxで標準のCUBICは増やし方の曲線が違いますが、「ロスを手がかりに、ゆっくり増やして思い切り減らす」という骨組みは同じです。

## 理解度チェック（1問だけ）

物語では、三十七番がなくなったことに**砂時計切れで気づいた場合**と、**同じ札が三枚届いて気づいた場合**とで、ヨウの「慎み」の扱いが違っていました（前者は「一つ」からやり直し、後者は半分にして続行）。

**なぜ扱いを変えるのが理にかなっているのでしょうか。** 橋（ネットワーク）の様子がどう違うと考えられるかに注目して、自分の言葉で答えてみてください。物語の言葉のままでも、TCPの用語を使ってもかまいません。

答えを見て、次は「スロースタートを実際の数字で追ってみる」か「フロー制御と輻輳制御の違いをもう一段深掘りする」か、どちらに進むか一緒に決めましょう。
