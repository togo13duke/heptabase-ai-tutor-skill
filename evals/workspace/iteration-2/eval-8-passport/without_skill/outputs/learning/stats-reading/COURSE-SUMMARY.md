- 作成日：2026-11-08
- 範囲：Session 001〜002（T1.P1、T1.P2）

## 一枚で言うと
- **標準偏差（σ、論文では SD と書かれることが多い）**＝ばらつきのものさし。「平均からだいたいどれくらい離れているか」。
- **p値**＝偶然だけでこうなる珍しさ。「差はない」と仮定したとき、今回と同じかそれ以上に極端な結果が出る確率。
- **p値は、仮説が正しい確率ではない。結果が偶然である確率でもない。**[S1: 原則2](https://doi.org/10.1080/00031305.2016.1154108)

## 2. p値　[T1.P2](sessions/002/PART-01.md)
| | |
| --- | --- |
| あだ名 | 偶然だけでこうなる珍しさ |
| 一言で | 「差はない」と仮定したとき、今回と同じかそれ以上に極端な結果が出る確率 |
| 前提の名前 | 帰無仮説＝「差はない」という仮の前提 |

**よくある誤読と言い換え**
| 誤読 | どこがずれているか |
| --- | --- |
| 「p = 0.03 だから、この薬が効かない確率は3%」 | p値は仮説が正しい（正しくない）確率ではない |
| 「p = 0.01 だから、この結果が偶然である確率は1%」 | 「差がないと仮定したときの珍しさ」であって、偶然である確率そのものではない（あなたの回答） |

覚え方：p値は **「仮定 → データ」** の向きの確率。「データ → 仮説が正しいか」の向きに読み替えたら誤読。

## 4. まだ回収していない近道
- **SC2：片側検定と両側検定の違い**（未回収）。今回扱った要旨はすべて両側検定なので問題なし。要旨に "one-sided" / "one-tailed"（片側）と書かれた論文を読むときに学ぶ。
- 補足（計算するときだけ関係）：論文の SD は通常「n−1で割る」版です。2つの値の例だと、この版では値が少し大きくなります（4点と8点なら約2.8）。読む・言い換える範囲では気にしなくて大丈夫です。

## 5. 勉強会で使える言い換えテンプレート
- SD：「平均 ○○ に対して、ばらつきはだいたい ±△△ くらいです」
- p値：「もし本当に差がないとしたら、これくらい極端な結果は p＝○ 程度の珍しさでしか出ない、という意味です。薬が効く確率が ○% という意味ではありません」
