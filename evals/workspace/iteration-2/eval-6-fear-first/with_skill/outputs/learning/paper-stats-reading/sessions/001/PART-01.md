# T1.P1 σを「ばらつきのものさし」として読む
- 目安：約15分
- 到達点：論文で SD や σ を見たとき、その集団の様子を一言で言える。
- 資料：指定なし。例・数値はすべて自作。

## 手が止まる場面
論文の表に「M = 60.0, SD = 14.1」と書いてある。M は平均（mean）なので読める。でも、その隣の SD や σ で手が止まる。多くの人がここで統計の部分を読み飛ばします。

けれども σ が答えている問いは一つだけです。しかも、平均を計算できる人ならもう半分持っている問いです。

> 平均は分かった。で、みんなその平均の近くにいるの？ それともバラバラ？

## 例（自作）：平均が同じ2つのクラス
5人ずつのテスト（100点満点）。

| | 5人の点 | 平均 |
| --- | --- | --- |
| A組 | 58, 59, 60, 61, 62 | 60 |
| B組 | 40, 50, 60, 70, 80 | 60 |

平均はどちらも60点です。平均だけを見ると同じようなクラスに見えますが、中身はかなり違います。一人ひとりが平均の60点から何点離れているかを書き出すと、こうなります。

| | 平均からの離れ（点） |
| --- | --- |
| A組 | 2, 1, 0, 1, 2 |
| B組 | 20, 10, 0, 10, 20 |

この「離れ具合」をならして一つの数にしたものが σ です。A組は約1.4点、B組は約14.1点になります。

- ならし方には決まった手順があり、今日は省いています（近道SC1）。
- 計算の流儀によって、A組は1.6点、B組は15.8点と書かれることもあります（近道SC2）。

どちらの場合も「A組は小さく、B組は大きい」という読み方は変わりません。

検算：A組 離れの二乗 4+1+0+1+4=10、10÷5=2、√2≈1.41。B組 400+100+0+100+400=1000、1000÷5=200、√200≈14.14。÷4 の場合は √2.5≈1.58、√250≈15.81。

## 4段階で
1. **あだ名**：ばらつきのものさし
2. **一言で**：みんなが平均から、だいたい何点（何cm、何時間）離れているか
3. **最小の例**：A組は約1.4点なので、全員が60点のすぐそばにいる。B組は約14.1点なので、40点の人も80点の人もいる。
4. **正式名称**：標準偏差（standard deviation）。論文では SD、s、σ（シグマ）と書かれる。今の段階では、どれも同じ「ばらつきのものさし」と読んでかまいません（違いは近道SC2で回収）。

もう一つ大事な点：σ の単位はデータと同じです。点数なら「点」、睡眠なら「時間」。だから「平均60点、SD 14点」は「60点を中心に、14点くらいの幅で散らばっている」と、そのまま日本語にできます。

## 今は気にしなくてよいこと
- σ を自分で計算する方法。論文を読むときは、書かれている数字を読めば足ります。自分で計算したくなったら、SC1を回収するときに一緒にやります。
- 論文の「60.0 ± 14.1」の「±」の後ろが σ なのかどうか。実は別の数（SE）のこともあります。次回 T1.P2 で見分け方を扱います。

## よくある誤解と、たとえが通用しないところ
- 誤解「SDが大きい＝データが悪い、測定ミスが多い」：SDが大きいのは、集団の中に違いがあるというだけです。B組は失敗したクラスではなく、得意な人と苦手な人が混ざっているクラスです。
- 誤解「SD＝最高点−最低点」：B組の最高点と最低点の差は40点ですが、SDは約14点です。SDは端の2人ではなく、全員の離れ具合から作られます。
- ものさしのたとえの限界：σ は「全員がこの幅の中に入る」という柵ではありません。A組でも、σ（約1.4点）より遠い人が2人（58点と62点）います。σ は集団の「だいたいの離れ具合」です。
