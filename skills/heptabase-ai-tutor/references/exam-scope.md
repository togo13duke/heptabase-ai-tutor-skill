# 試験・資格が目標のとき

合格が目標のコースでは、学ぶ範囲を決めるのは教科書の目次ではなく、公式の出題範囲である。範囲を先に固定し、どこを深く、どこを浅く扱うかを本人と決める。教え方、理解の判定、記録の形式は通常のコースと同じものを使う。

## 1. 出題範囲を資料として読む

- 公式の試験ガイド（出題範囲、項目ごとの配点比率、合格ライン、出題形式、試験時間、版・改定日）を最初の資料として取得し、`SOURCES.md` に版と取得日を記録する。
- 出題範囲は改定される。記憶から再現せず、取得できなければ本人に貼ってもらうか、URL・PDFを頼む。取得できないまま始める場合は、範囲が未確認であることを `GOAL.md` とシラバス案に書き、確認できた時点で対応を作り直す。
- 配点や合格ラインが公開されていない試験では「非公開」と記録し、数値を推定で埋めない。
- 受験予定日と、すでに受けた模試・練習問題の結果は、分かっていれば使う。分からなければ他の不足情報と一緒に一度だけ聞く。
- 範囲内の内容は公式ドキュメントなど確認できる資料で裏付ける（SKILL.md 第2節）。本試験の問題の再現や流出した問題は資料にしない。

## 2. 出題項目をシラバスに対応させる

`SYLLABUS.md` に「出題範囲との対応」の表を作る（テンプレートは course-templates.md）。

- 行は公式ガイドの出題項目。番号と名前は公式の表記をそのまま使う。
- すべての項目を、対応するTopic/Partか「対象外」のどちらかにする。空欄を残さない。「対象外」には理由を書き、本人に見せて合意を得る。
- 一つのPartが複数の項目に対応してよい。Part名は出題項目名の写しにせず、学習者のためにすることにする（teaching-style 第3節）。
- 理解の状態はTopic/Partの行が基準である。対応表には状態を重ねて書かず、対応と扱う深さだけを書く。

## 3. 扱う深さを決める

合格ラインは満点ではない。全項目を同じ深さで扱うより、配点と本人の現在地に合わせて配分する。

| 扱い | 使う場面 |
| --- | --- |
| 深く | 配点が大きく、未経験または誤答が出ている項目 |
| 標準 | 配点が中程度、または経験はあるが実回答で確かめていない項目 |
| 要点のみ | 配点が小さい項目、または実回答で理解を確かめた項目 |
| 対象外 | 本人と合意して今回は扱わない項目 |

- 「経験がある」という自己申告だけで要点のみ・対象外にしない。短い現在地チェック（starting-point.md）か、持ち込まれた模試の結果で確かめる。
- 配点が小さい項目も、一度は触れる。用語と見分け方だけの短いPartでよい。
- 受験日までの回数と1回の時間から、全体が収まるかを見積もる。収まらなければそのことを伝え、何を浅くするかの案を示して選んでもらう。黙って項目を落とさない。
- 深さを決めた理由（配点、実回答、本人の希望）を表に一言残す。

## 4. 試験の形式に合わせて確かめる

- 選択式の試験でも、理解の判定基準は変えない。選択肢を当てただけでは `demonstrated` にせず、なぜ他の選択肢ではないかを一言聞く。
- 確認問題には、試験と同じ形式の問い（紛らわしい選択肢の見分け、場面から適切な機能・設定を選ぶ）を混ぜる。問題は資料をもとに自作し、「自作」と区別する。実際の出題であるかのように見せない。
- 画面や手順を知らないと答えにくい項目は、練習ルート（teaching-style 第8節）で実際の操作を確かめる。
- 模試や練習問題で間違えた問題は、SKILL.md 第5節「外で間違えた問題を持ち込む」で扱う。見つかった弱点に合わせて対応表の扱いを見直し、変更履歴に理由を残す。

## 5. 再開と修了

- 再開時は、扱いが「深く」で `unverified`・`developing` の項目を、想起問題と次のPartの候補として優先する。
- 試験ガイドが改定されたと分かったら、新しい版を別の資料として記録し、対応表の差分を本人に示してから更新する。
- `PASSPORT.md` の「できるようになったこと」と「扱ったが未確認」は、出題項目ごとに分けて書く。対象外にした項目も残す。
- スキルが示すのは範囲の対応と学習の記録であり、合格を保証しない。得点の予測もしない。
