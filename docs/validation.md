# 検証の範囲

2026-11-07。これは初版の動作確認であり、長期学習効果の測定ではない。

## 形式・参照

- skill-creator付属の `quick_validate.py`：合格。
- スキル内の実ファイル参照：すべて解決。コード中の例示URLは対象外。
- `.agents/skills/` と `.claude/skills/` の入口：同じ本体を指すことを確認。
- 専用ランタイム、APIキー、MCPを必須にしない構成。

再検証する場合は、インストール済みskill-creatorの `scripts/quick_validate.py` に `skills/heptabase-ai-tutor` を渡す。検証ツールはPyYAMLを使うが、学習スキル自体にPython依存はない。

## 対話と保存

3件をスキルあり・なしで実施。別々の評価エージェントが同じ初期ファイルから一回の応答を行い、親エージェントが応答と実ファイルを確認した。

| ケース | 確認したこと | スキルあり / なし |
| --- | --- | --- |
| 初回学習 | 背景を利用、小さな説明で待機、未確認として保存 | 3/3・3/3 |
| 再開 | 保存済みの問題を再提示、答えを代筆しない、未確認を維持 | 3/3・3/3 |
| 難易度調整 | 範囲を縮小、チェック省略を尊重、過去教材と再開位置を保持 | 3/3・3/3 |

この小さいケースではベースラインも全項目を満たした。優位性・自動起動率・教材の品質向上は実証していない。スキルありでは所定のゴール・シラバス・進捗・セッションファイルへの整理を観察した。計測可能な実行時間・トークン統計は返されなかったため比較しない。

## MCP入力の追加確認

NotebookLMの「照会のみ可能」と、Heptabase指定時の「接続なし」を模擬した。模擬ツール結果からの応答・ローカル保存を確認するもので、サービスへの実接続テストではない。入力先への書き込みは行わない。各ケース3/3項目を満たし、照会回答と原文の区別、出典ID、ローカル保存、未接続時の代替案を確認した。

[評価ビューア](../evals/review.html)で応答・採点根拠を閲覧できる。

各ケースをスキルあり・なしで1回ずつ実行した。別々の評価エージェントが同じ初期状態から1ターンだけ応答し、親エージェントが応答と保存ファイルを読んで採点した（盲検ではない）。結果は `evals/workspace/iteration-2/` にある。

記録の点検（`check_course.py`）：スキルありは4件ともエラー0・注意0。スキルなしはエラー計5件・注意1件。ただし、スキルなしはこの形式を知らないので、この数値は参考値である。

注意すべき点：
- **ケース7**：スキルありは「新しい説明の前に想起一問」の規則に従って想起問題で止まり、回収は次のターンの計画に書いた。1ターンの評価では回収を観察できないため、ケース7を「想起の回答を受け取るところ」から始める形に改訂した。改訂版（`iteration-3/`）では、スキルあり3/3、スキルなし2/3。どちらも前の説明とつなげて回収し、`paid` にした。差は記録の値（なしは独自の `verified` を使い、点検でエラー1件）だけで、回収の振る舞い自体には差がなかった。スキルなしも、初期記録の SHORTCUTS.md を読んで回収している。スキルありの応答は約2900字（なしは約1300字）で、回収とp値のPartを1回の応答に含めていた。
- **ケース8**：スキルなしも、スキル形式で書かれた初期記録（REVIEWの判定、SHORTCUTS）を読んで高い質のまとめを作った。差の一部は、記録の形式そのものの効果である。
- 寓話の質（ケース9）はどちらも高く、内容に誤りは見つからなかった。差は進め方（推測の機会）にある。
- スキルありのケース6の応答は、シラバスとPart全体を一度に含み長い。数分で読める分量という規則の範囲かは、実際の学習者で確かめていない。

評価で見つかり、直したこと：
- 点検スクリプトが `想定解：` 形式の答えの書き込みを見逃していた。検出する語を増やし、破損フィクスチャで確認した。
- 模範フィクスチャのp値のあだ名「偶然だけでこうなる珍しさ」が、ASA声明の原則2が否定する読み方に寄っていた。スキルありの実行が作業計画の中で指摘した。あだ名を直し、teaching-style 第2節に「あだ名が誤解をそのまま言っていないか確かめる」を加えた。
- ケース8のスキルありは、初期記録の時刻（評価者が仮に置いた20:10）より後になるよう、更新日時を推定値にしていた。初期状態の作り方による副作用である。
